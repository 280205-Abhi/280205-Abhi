## 📂 Featured Projects

### 🏨 [Hotel Booking Analysis](https://github.com/280205-Abhi/Hotel_Booking_Analysis)
End-to-end EDA on **119K+ bookings** to find what drives cancellations and where revenue leaks.

- Removed **31,994 duplicate rows (26.8%)** and engineered 8 new features
- Quantified **€11.47M lost to cancellations (33% of potential revenue)**
- Ranked cancellation drivers with logistic regression: lead time is #1, special requests the strongest protective factor
- Found the *non-refundable deposit paradox* and delivered 6 business recommendations · [Executive report ↗](https://drive.google.com/file/d/1sXUeJZfLIHa84kZxPm1ZcQuG0lCqpnpA/view?usp=drive_link)

`Python` `Pandas` `Seaborn` `Plotly` `Scikit-learn`

### 🧠 [NeuroAI: Explainable Decision Support for ASD Screening](https://github.com/280205-Abhi/NeuroAI_ASD)
Multimodal screening support combining **brain MRI, the M-CHAT-R questionnaire and clinical features**, with explanations clinicians can inspect. Team project; I built the FastAPI backend, the React frontend, and the MRI model with Grad-CAM++.

- Clinical: Random Forest at **96.55% test accuracy**, Gradient Boosting for severity
- MRI: ResNet18 + EfficientNet-B0 ensemble, **84.21% accuracy, 0.9117 AUROC**
- **10+ models benchmarked**; SHAP explanations and auto-generated PDF reports

`Python` `PyTorch` `FastAPI` `React` `SHAP`

### 🌐 OpenSource Pulse *(in progress)*
What makes open-source projects thrive or go quiet, analysed via the GitHub REST API.

- Collected metadata for **800 public repos** across 8 languages (active, dormant and archived)
- Building a **"thriving vs abandoned" health score** and tracking language popularity shifts
- Next: searchable repo-health dashboard with trend charts

`Python` `SQL` `GitHub API` `Jupyter` `Plotly`
